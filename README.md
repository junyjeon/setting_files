# Setting_files

여러 기기에서 사용하는 개인 설정 파일 모음이다.

## Claude Code 전역 설정

전역 `~/.claude` 설정의 수동 동기화 원본은 [`claude-home/`](claude-home/)에 있다.

- 저장소의 `.claude/`는 이 프로젝트에서 사용하는 기존 프로젝트 설정이다.
- `claude-home/`은 다른 기기의 `~/.claude`에 선택적으로 적용하는 공유 설정이다.
- 세션, 로그, 캐시, 인증정보 및 플러그인 생성 파일은 동기화하지 않는다.

가져오기와 적용 방법은 [`claude-home/README.md`](claude-home/README.md)를 따른다.
